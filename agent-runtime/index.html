工程落点

参考设计建议 将入口、执行器、队列、流式网关、模型网关、工具池与状态分片分别扩容；依靠事件、检查点、幂等键与租户键建立恢复和隔离边界。

统一 Agent Runtime 分层模型

以下全部是参考设计建议，不表示任一厂商已按此部署。

执行面

  1. 入口验证身份并生成请求标识。
  2. 可信租户路由决定区域、策略和资源池。
  3. Agent Loop 装载上下文，调用模型，执行工具并回填结果，直到完成或触及轮次、时间、成本上限。
  4. 模型网关集中管理凭证、选择、配额、超时和重试。
  5. 工具面分离结构化函数、远程 API、MCP、浏览器与隔离代码。

状态面

  1. 调度器将短任务与长任务分流。
  2. 流式事件具有 invocation、event、序号和恢复游标。
  3. 会话状态用版本条件写或单会话串行化维持顺序。
  4. 长期记忆按授权 scope 隔离并支持结构化过滤。
  5. 对象产物保存大文件，元数据保存归属、版本和校验和。
  6. 缓存键包含租户、权限与版本，且不是权威状态源。

控制面

  1. 可观测性贯穿 request、invocation、session、模型、工具、状态写入与成本。
  2. 安全治理覆盖权限、提示注入边界、密钥、加密、隔离、删除、审计与敏感追踪控制。

请求时序与异步生命周期

状态写入点：受理记录、队列记录、模型或工具步骤后的事件和检查点、工具幂等结果、会话最终版本、长期记忆、产物元数据与审计。故障边界：入口、流连接、队列、执行器、模型供应商、各类工具池、会话库、检查点、索引与对象存储分别隔离。扩容单元：入口、活动连接、交互执行器、异步消费者、模型并发槽、每类工具池和各状态分片独立伸缩。

多用户高 QPS：容量是多维约束

接入与扩缩

  • 入口保持无状态，按并发连接、请求率和 CPU 横向扩缩。
  • 准入控制在创建昂贵工作前检查租户配额、全局水位和预算。
  • 交互与批处理分队列，设置有界容量、优先级和公平调度。
  • 背压从模型、工具、数据库逐级传回，拒绝或排队优于无限堆积。

顺序与可靠性

  • 单会话用分区消费者、租约锁或版本条件写串行化；避免全局锁。
  • 重试只用于可判定的暂态错误，指数退避并带抖动。
  • 所有副作用携带幂等键；超时不等于失败，先查询结果再重放。
  • 按租户与 session 哈希分区，监测大租户、长会话和热点工具。

模型、工具与流

  • 模型和每类工具各有独立并发信号量、速率限制和熔断器。
  • 流式连接从执行器解耦，慢消费者有缓冲上限和恢复游标。
  • 沙箱按镜像、资源和信任等级分池；冷启动与占用时长单独容量规划。
  • 降级顺序预先定义：缩短上下文、关闭非关键工具、切模型、转异步或明确拒绝。

成本与恢复

  • 按租户记录 token、模型时长、工具时长、沙箱秒数、检索与存储。
  • 队列、检查点和租约使执行器崩溃后可恢复；连接断开不取消耐久任务。
  • 跨区恢复明确 RPO / RTO；先恢复权威状态，再重建缓存和向量索引。
  • 容量估算同时约束 QPS、活动流、模型槽、工具槽、数据库 IOPS 与队列滞留。

必须观测的 SLI / SLO

准入成功率、端到端成功率、首 token 延迟、完成延迟、流中断率与续传成功率、队列深度和最老任务年龄、模型与工具错误率、重试与幂等命中率、会话版本冲突率、检查点恢复成功率、热点分区、各租户限流率、token / 工具 / 沙箱成本，以及敏感数据和越权告警。没有厂商直接来源时，本报告不提供产品真实 QPS、用户量、延迟或存储规模数字。

可靠性、安全与治理

可靠执行

  • 事件先耐久化再广播，消费者以序号去重。
  • 工作器用租约领取，检查点提交与副作用结果分开记录。
  • 模型和工具故障域隔离，超预算任务进入死信或人工处置。
  • 降级行为对用户可见，不把部分失败包装为成功。

租户与权限

  • 租户键来自服务端身份上下文，客户端字段仅作输入。
  • 工具在执行时重新授权，不继承模型文本中的权限声明。
  • 队列、缓存、向量过滤、对象路径与日志使用同一授权范围。
  • 大租户使用独立配额、分区或资源池控制 noisy neighbor。

提示注入边界

  • 网页、文件、工具输出和记忆均是不可信数据。
  • 系统策略与工具授权不可由检索内容改写。
  • 高风险副作用要求结构化校验、最小权限和必要的人工确认。
  • 追踪默认脱敏，敏感正文采用受控采样和短保留。

术语表

Agent Loop
在模型输出、工具调用、工具结果和最终答案之间迭代的控制循环。
Session / Conversation / Thread
各平台语义不同；本报告统一指一组有权限边界和顺序关系的交互状态。
Memory
跨步骤或跨会话保留、可在后续调用中召回的信息；不等同于完整聊天历史。
Checkpoint
足以从某个边界恢复执行的耐久状态快照或状态引用。
Event
带顺序的运行事实或增量，可携带状态变化、工具结果或产物引用。
Invocation
一次 Agent 执行实例，可包含多次模型调用与工具步骤。
Artifact
由用户、模型或工具产生的文件、报告、图像、代码包等对象及其元数据。
Tenant
共享基础设施上的授权与计费隔离单元，可能对应组织、项目或账户。
幂等
同一逻辑操作重复提交不会产生重复副作用的性质。
